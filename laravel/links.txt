========== change version of php in laragon ======
1- open laragon
2- click on menu > php > version > select version of php
----- change version of php in laragon in c ============
1- open c 
2- open laragon folder > bin > php > copy folder of php 8.3 (un zip (فاكك الضغط للفولدر)) > select version of php > copy the path of php
------- path of version of php in laragon : C:\laragon\bin\php\php-8.3.30-Win32-vs16-x64

3- open php8.3 ==> copey from php-ini-development > rename to php.ini > remove ; from these extensions

-- extensions in php.ini 
extension=bz2
extension=curl
extension=fileinfo
extension=gettext
extension=mbstring
extension=mysqli
extension=openssl
extension=xsl
extension=zip

4- open environment variable >  click on path (system  variables ) > edit > new > paste the path of php 8.3
