=== request

== promise 
readyState tracks the progress of the network request itself (whether the communication cycle is complete).

status tracks the server's HTTP response code (whether the server successfully processed your request).


server data (response status) :
200 → Success  (data already retrieved)
404 → Not Found
401 → Unauthorized   || authentication : (login , register) || authorization : acces control (admin , user , guest)
403 → Forbidden
500 → Server Error

readyState
xhr.readyState (Request Progress)
This property tells you which stage the request is currently in. It progresses through 5 numerical states (0 to 4):

0 (UNSENT): The XMLHttpRequest object has been created, but .open() has not been called yet.

1 (OPENED): .open() has been called and the connection is established.

2 (HEADERS_RECEIVED): .send() has been called, and response headers have been received.

3 (LOADING): Downloading the response body; data is actively arriving.

4 (DONE): The operation is complete. The entire response has been received (regardless of whether it was successful or failed).
